# data

`silica_Q3_amorph_4_7OH.mol2`: INTERFACE FF 1.5 のアモルファスシリカ表面モデル
`silica_Q3_amorph_4_7OH_0pct_ion`（2,928 原子、Q3、シラノール末端、非イオン化）を、
型（sc4, oc23, oc24, hoy）と電荷を保ったまま MOL2 に変換したものです。
元の `.car` / `.mdf` は `external/iff/` にあります。x, y を周期セルに折り返し、z を
+2.0 Å 平行移動しています（剛体操作のみ、結合長の変化は 6e-15 Å 以下）。
出典と引用は `external/iff/README.md` を参照してください。
